@thirkettle/data-explorer examples

Each example is one data set and one SceneSource. The source code is in packages/data-explorer/examples/.

  • A file tree A tree of packed scenes. Windowing with an honest aggregate, a colour ramp, and ring emphasis.
  • A module dependency graph Radial neighbourhoods with typed edges, a tagged-union focus, and cycles you can walk round.
  • A streaming atlas Scenes that stream in pages, live invalidation, a custom ramp, and light/dark re-tinting.
  • A solar system Item textures cropped to their shape, a no-CORS failure, a pulsing sun, orbit edges and a tiled starfield.
  • An org chart A tree of departments and teams into a radial person view: manager and reports as edges you can walk. Built from the docs alone, as the US072 cold-start test.
  • Stress test One big scene with its size and edge styles in the query string, for measuring draw cost.
