The minimum: a tree of packed scenes, a string focus, and a `parentOf` that is always `anchored`. Also `windowed` with an honest aggregate (`assets/icons` holds 420 files and draws 120, with a hollow cluster saying how many it left out), `ramp` for file age, `emphasis: ["ring"]` for uncommitted changes, and `invalidate()`: switch to colouring by type and each file carries its own `color`, recoloured in place.

The frame below runs the example built from exactly these files. Start with `source.ts`. Every
example shares one small page shell (`examples/shared/ExampleShell.tsx`): it keeps the focus in the
URL hash, builds a breadcrumb from `onSceneChange`, and shows the selected item from `onNodeSelect`.
