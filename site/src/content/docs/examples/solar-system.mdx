Item `texture`s cropped to their disc, custom renderers by item `kind` (planets with a night side and rings), `edges` as orbits, a `pulse` on the Sun and an image `background`. Pluto's face is on a host that sends no CORS header, so it keeps its plain disc and `onTextureError` reports it: see [Images and CORS](/data-explorer/guides/images-and-cors/).

The frame below runs the example built from exactly these files. Start with `source.ts`. Every
example shares one small page shell (`examples/shared/ExampleShell.tsx`): it keeps the focus in the
URL hash, builds a breadcrumb from `onSceneChange`, and shows the selected item from `onNodeSelect`.
