A graph reached through a tree. The focus is a tagged union, and a module's scene is **radial** (`focusId`): what it imports as discs, what imports it as squares, the edges drawn. Every neighbour drills into its own neighbourhood, so you can walk round the import cycles. It logs every event, and has a toggle that turns activation into "open details".

The frame below runs the example built from exactly these files. Start with `source.ts`. Every
example shares one small page shell (`examples/shared/ExampleShell.tsx`): it keeps the focus in the
URL hash, builds a breadcrumb from `onSceneChange`, and shows the selected item from `onNodeSelect`.
