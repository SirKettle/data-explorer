Real country shapes in [fixed scenes](/data-explorer/guides/fixed-layouts/): Natural Earth's 110m countries from `world-atlas`, projected once with `d3-geo` into one set of map units, and drawn as `region`s with their own `outline`s. Continents enter to their countries, which land exactly where the continent was drawn. Lesotho is a hole in South Africa's outline, and each label sits at its country's `labelAt`, the middle of its biggest piece.

The frame below runs the example built from exactly these files. Start with `source.ts`; `data.ts` is the projection, which the explorer never sees. Every
example shares one small page shell (`examples/shared/ExampleShell.tsx`): it keeps the focus in the
URL hash, builds a breadcrumb from `onSceneChange`, and shows the selected item from `onNodeSelect`.
