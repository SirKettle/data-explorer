Five small apps with made-up data and nothing else underneath, plus a stress page for measuring.
Each shows a different part of the contract, and each page runs the example beside the source it was
built from.

| Example | What it shows |
| --- | --- |
| [A file tree](/data-explorer/examples/file-tree/) | The minimum tree; `windowed` aggregates, `ramp`, `ring`, `invalidate`. |
| [A module graph](/data-explorer/examples/module-graph/) | Radial scenes over a graph with cycles; every event logged. |
| [A streaming atlas](/data-explorer/examples/atlas/) | Streaming scenes, invalidation, live palettes and backgrounds. |
| [A solar system](/data-explorer/examples/solar-system/) | Textures, custom renderers, edges as orbits, a texture refused by CORS. |
| [An org chart](/data-explorer/examples/org-chart/) | A tree into radial people; a headless smoke test. |
| [Stress test](/data-explorer/examples/stress/) | One big scene with the stats overlay. |

To run them locally from a clone of the repository: `bun install`, then `bun run examples`.
